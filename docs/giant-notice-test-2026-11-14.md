# 거대 수행평가 안내문 30종 점검 (2026-11-14)

`수행평가 안내문/거대 수행평가 안내문/`의 34종 중 30종을 각 1회 생성했다(한문·가정-03·국어-02·과학-09는 제외 — 생성물이 없는 시험범위 공지,
활동지 사진 없음, 문제풀이 시험이라 점검 대상이 아니다. 수학-01은 도구 시험 실행이 곧 본 실행이다).
안내문 사진은 사람이 직접 읽어 `scripts/measure/giant-cases.ts`에 **안내문에 적힌 조건만** 체크리스트로 적었고(학생이 고를 책·주제·진로는 지침으로 줌),
`scripts/measure/giant-check.ts`가 analyze → generateEssay/generatePlan → 채점 → 시간·분량·출처·결함 측정을 한 번에 한다.
생성은 서버 경로를 타지 않으므로 쏠림 억제·임베딩에 영향이 없다. 총 비용 약 $1.25.

**표본이 과제당 1회라 흔들림은 못 본다.** 아래 수치는 "이번 한 번"이다(PROGRESS의 흔들림 문제 때문에 다음 실행에서 달라질 수 있다).

## 진짜 결함 (원문을 직접 확인한 것)

1. **안내문에 인쇄된 문항 내용이 분석에서 사라져 생성이 다른 문제를 지어 답했다 — 사회-05(유전체 윤리)**
   안내문 "확인 문제"의 ○/× 3문항과 보기 ㄱㄴㄷ를 분석이 옮기지 않아, 생성은 "유전자 검사는 서면 동의가 필요하다" 같은 **없는 진술**을 만들어 ○/×를 매겼다(안내문 정답은 (1)○(2)○(3)× / ㄱㄴㄷ).
   11-11 사회 "경제적 유인" 때 `provided_materials`(안내문에 실린 자료를 숫자까지 옮기는 칸)로 고친 것과 같은 뿌리다. 객관식 문항·보기도 그 칸에 들어가야 한다.
2. **실제 있지도 않은 참고 도서를 만들었다 — 역사-05**: "『일제강점기 독립운동 개론서(근현대사 교과서 수준의 입문서)』", 저자는 "정보 미상". 안내문이 도서 제목·저자를 요구하는데 지침에 책이 없으면 **지어내지 말고 `[직접 작성]` 빈칸**이어야 한다(제품 원칙: 개인 경험·서지는 지어내지 않는다).
3. **계산이 틀린 수치에 출처 각주를 달았다 — 수학-02**: 월 50만 원 36개월 단리 이자를 "111만 원[7]"로 썼는데 실제는 105만 원(630개월분×50만×4%/12). 같은 글의 [1] 보고서는 "매월 말", [2] 분석은 "매월 초"로 납입 시점도 어긋난다. 계산한 값에 검색 출처 각주를 붙이는 것이 문제다.
4. **소제목이 본문 한 줄에 뭉쳐 나왔다 — 수학-01, 역사-01(채점 모델 지적)**: 수학-01은 "부분 보완"(`generate-essay.ts` 4800~4830줄 부근)이 줄바꿈을 지우고 돌려준 글을 그대로 채택했다. 보완 결과가 `###`를 줄 처음에 유지하는지 검사하는 한 줄이 없다. 전체 30편 중 줄 중간 `###`는 수학-01 1건만 기계 검출됨.
5. **분석이 평가 영역 전체를 글 단계로 만들었다 — 사회-04**: 공지문에 탐구주제선정·인물인터뷰·독서·수업과정평가 네 영역이 나열돼 있고 이번 수행평가는 앞의 하나인데, 글 단계 4개(인물 인터뷰 보고서·독후감까지)를 만들어 **51.1초·$0.112**가 들었다. 비용·시간·날조(사회-04 2건) 모두 여기서 나왔다.
6. **안 해도 되는 외부 제작 단계를 만들었다 — 정보-01(60.3초)·과학-08(65.1초·$0.141)**: 정보-01은 "발표(희망자만)", 과학-08은 "3차시: 슈퍼스쿨 입력"인데 발표 자료/PPT 계획까지 생성했다. 이 둘이 이번 시간·비용 상위 3개 중 둘이다.
7. **사진을 이미 준비했다고 씀 — 역사-03**: "사진은 … 총 4장을 준비했다." 제출문에 학생이 하지도 않은 일을 단정(안내문: 사진은 학생이 준비). 같은 글에 그림 그리는 방법 안내도 없다.
8. **학생이 직접 하는 자기평가를 대신 채움 — 과학-07**: "양적 관계 이해: 3". (측정값 계산은 전부 정확했다 — 0.010·0.020·0.030 mol.)
9. 그 외 작은 것: 과학-01 참고문헌 목록·추가 자료(그림) 누락(서론-본론-결론-참고문헌-요약 형식 요구), 정보-01 제목이 "탐구 보고서"뿐, 과학-10 뒷정리·오차 해석 누락(실험 보고서 틀), 사회-02 "다양한 환경 문제 찾기" 없이 바로 한 주제, 국어-01 책이름 칸에 문장 서술.

## 다음에 할 것 (제안, 우선순위 순 — 미착수)

1. 분석이 안내문에 인쇄된 **객관식 문항·보기·정답 표시 칸**을 `provided_materials`에 그대로 옮기게 하고, 생성이 그것을 푼다(1번).

3. 부분 보완 결과의 소제목 줄바꿈 보존 검사(4번, 한 줄).
4. 외부 제작 단계 판정: "희망자만"·"선택" 발표와 사람이 직접 입력하는 단계는 생성 대상에서 뺀다(6번) — 시간 상위 3개 중 둘.

6. 계산한 수치에 검색 각주를 붙이지 않는 검사(3번).

각 항목은 `rule-audit.ts`에 문구 변형을 먼저 추가하고 `audit.ts` 전·후 비교 후 생성 1회로 확인할 것(PROGRESS 작업 순서).
