## 4. "ChatGPT와 같은 API인데 왜 품질이 다른가" — 확인된 원인

1. **모델이 다르다.** 앱은 모든 호출이 gpt-5-mini이고 글쓰기는 추론 강도 minimal이다. ChatGPT는 더 큰 GPT-5 계열에 추론을 켜서 답한다. 같은 회사 API라도 같은 모델이 아니다.
2. **글쓰기 모델이 안내문 사진을 보지 못했다.** 분석이 사진을 짧은 요약으로 바꾸고, 채점 기준은 "화면 표시 전용" 행정정보로 빠져 생성에 전달되지 않았다. 새 필드 `core_task_info.writing_guide`(채점 기준의 내용·형식, 칸 구성, 예시 형식·분량)로 전달하게 바꿨다.
3. **과제와 무관하고 서로 충돌하는 규칙 과적재**(이전 점검) + 외부 제작 경로에는 품질 수정이 하나도 적용돼 있지 않았다 → 외부 제작 경로도 조사→글쓰기로 바꾸고 같은 규칙·정리 단계를 적용.
4. **버그로 인한 재생성이 글을 흔들었다**(위 비용 표의 거짓 경보들).

A/B(글쓰기만 gpt-5.4-mini, 3회): 한국어 문장이 눈에 띄게 자연스럽고(책 처방전 각 단계 450~730자, 학생 말투) 영어 칸 구성도 따랐다. 반면 근거 번호를 빠뜨린 사실 문장이 늘고 음역 오류("마리 곤스")가 있었다. 비용은 회당 약 +$0.006. **3회로는 결론을 못 내서 기본값은 바꾸지 않았다**(`OPENAI_MODEL_WRITE=gpt-5.4-mini`로 켤 수 있음).
